# ClinicAI 🩺
An AI-powered logic tool to help users identify symptoms and find real medical professionals in their city.

## 🚀 Features
- **Symptom Checker:** Logic-based assessment for Fever, Chest Pain, and Skin Rashes.
- **Live Doctor Search:** Integrates with OpenStreetMap API to find clinics in cities like Patna.
- **Secure Profiles:** Local authentication for patient records.

## 🛠️ Tech Stack
- **Language:** Python 3.14
- **Environment:** Self-hosted on Chromebook (Nix/venv)
- **APIs:** OpenStreetMap (Overpass API)
- **Deployment:** GitHub Version Control
